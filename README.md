# Python Multiple Inheritance

## Explanation

Multiple inheritance is an Object-Oriented Programming concept where a single child class inherits from more than one parent class.

This program demonstrates how a `Student` class can inherit functionality from both `Person` and `Course` classes.

## Problem Statement

Write a Python program to demonstrate multiple inheritance using two parent classes and one child class.

## Features

* Demonstrates multiple inheritance
* Uses two parent classes
* Uses one child class
* Reuses methods from both parents
* Demonstrates code reuse

## How It Works

1. The `Person` class stores personal information.
2. The `Course` class stores course information.
3. The `Student` class inherits from both classes.
4. A student object is created.
5. The object can access methods from both parent classes.

## Technologies Used

* Python 3
* Object-Oriented Programming
* Classes
* Multiple Inheritance

## Program Flow

Start → Create Parent Class 1 → Create Parent Class 2 → Create Child Class → Inherit Both Parents → Create Object → Display Details → End
